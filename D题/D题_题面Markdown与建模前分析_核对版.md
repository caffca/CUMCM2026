## 2. 题面 Markdown 化

### 2.1 背景与资源离散化

随着用频装备数量增加，制定计划时需检测并消解用频装备间潜在的时频冲突。题目考虑某区域中多个装备在同一有限频率资源上、不同时间段的使用需求。

题面将时频资源离散化：

- 时间基本单位为 $\Delta t$；任一计划占用时长必须是 $\Delta t$ 的整数倍；
- 可用频率资源被划分为 100 个等宽频段，每个频段宽度为 $\Delta f$；
- 单个计划可占用连续多个频段，且占用频段数在调整后保持不变。

每个用频计划给出四类参数：频段区间、首次使用的时间区间、相邻两次使用的间隔时长、使用次数。

> 当两个计划的时间区间和频段区间均存在交叠时，二者存在时频冲突。

冲突消解允许调整某些计划的参数（例如整体平移频段区间或时间区间），必要时也可撤销计划，最终要求所有保留计划无冲突。

### 2.2 一般约束与优先偏好

以下是题面明确给出的共同约束与偏好：

1. 一项计划**只能调整其中一个参数**，或者撤销；
2. 除问题 4 特别说明外，一般不调整使用次数和使用间隔时长；
3. 应尽可能少撤销计划，并尽量少调整计划；
4. 优先级为 A 类 > B 类 > C 类，高优先级计划应尽量保持；
5. 应尽量减小调整幅度；
6. 问题 2 中频段、时间平移的最大幅度分别为 $10\Delta f$、$5\Delta t$。

题面没有给出这些偏好的数值权重，也没有把它们写成严格的数学优先级序列。因此，在求解阶段需要公开采用的多目标规则；不能把某一套自设权重误写为题设唯一标准。

### 2.3 四个问题

#### 问题 1：冲突检测

检测附件 1 中所有用频计划的时频冲突，将冲突装备对填入 `result1.xlsx`，并在论文中报告冲突统计。

#### 问题 2：冲突消解

| 类别 | 保留数量 | 调整数量 | 撤销数量 |
|---|---:|---:|---:|
| A 类 |  |  |  |
| B 类 |  |  |  |
| C 类 |  |  |  |

#### 问题 3：增加 C 类装备

基于问题 2 得到的无冲突计划，在不增加时频资源、且不限制频段和时间平移幅度的条件下，最多安排多少新增 C 类装备；将新增计划填入 `result3.xlsx`。

## 3. 计划、周期与冲突的统一解释

### 3.1 半开区间与重复使用

题面以 A001 为例给出频段 `[80,90)` 和首次时间 `[35,40)`。下标采用半开区间语义：左端点包含、右端点不包含。因此，`[a,b)` 与 `[b,c)` 端点相接但没有共同的离散时间/频率单元。

对计划 $i$，记：

| 符号 | 含义 |
|---|---|
| $[F_i^L,F_i^R)$ | 频段区间 |
| $[s_i,e_i)$ | 首次使用的时间区间 |
| $d_i=e_i-s_i$ | 单次持续时长 |
| $g_i$ | 上一次使用结束至下一次使用开始的空档时长 |
| $n_i$ | 总使用次数 |

题面 A001 示例明确说明：间隔 $g_i$ 不是两次开始时刻之差；相邻开始时刻之差为 $d_i+g_i$。故第 $k$ 次（$k=0,\ldots,n_i-1$）使用时间为

$$
T_{ik}=[s_i+k(d_i+g_i),\ e_i+k(d_i+g_i)).
$$

### 3.2 严格的冲突判定口径

两个半开区间有正长度交集的条件为

$$
[a,b)\cap[c,d)\ne\varnothing
\quad\Longleftrightarrow\quad
\max(a,c)<\min(b,d).
$$

据此，计划 $i,j$ 发生冲突，当且仅当：

1. 频段区间 $[F_i^L,F_i^R)$ 与 $[F_j^L,F_j^R)$ 有交集；且
2. 存在某次使用 $k,l$，使 $T_{ik}$ 与 $T_{jl}$ 有交集。

输出层面应记录**装备计划对** $(i,j)$，而不是把同一对设备在不同重复时段的每一次相交分别写成多行。装备对的编号顺序也应固定，例如始终写为字典序较小的编号在前。

## 4. 专有名词和专业术语

| 术语 | 本题语境下的含义 | 可用于建模的抽象 |
|---|---|---|
| 时频资源 | 时间和频率共同构成的有限资源平面 | 离散二维格点 $(t,f)$ |
| 时域离散化 | 时间只能以 $\Delta t$ 的整数单位占用 | 整数时间槽 |
| 频域离散化 | 可用带宽分为 100 个等宽频段 | 100 个频率槽 |
| 频段区间 | 一个计划连续占用的频率槽范围 | 固定宽度半开区间 |
| 首次时间区间 | 第一次使用的开始、结束时段 | 初始时间窗 |
| 使用间隔 | 本次结束到下一次开始的空档 | 周期中的空闲部分 $g_i$ |
| 使用周期 | 两次使用开始时刻的距离 | $p_i=d_i+g_i$ |
| 时频冲突 | 时间与频率两个维度均重叠 | 两个周期时频矩形相交 |
| 平移 | 保持区间长度不变，只整体移动位置 | 整数偏移变量 |
| 撤销 | 不再安排该计划 | 计划不存在/可选状态关闭 |
| 冲突图 | 顶点表示计划或候选状态，边表示不能同时选 | 图论中的互斥关系图 |
| 词典序多目标 | 先优化较重要目标，再在该最优值下优化下一目标 | 可审计的分层优化 |

## 5. 附件 1 的数据画像

### 5.1 结构与质量检查

`附件1.xlsx` 的唯一工作表为 `Sheet1`，范围为 `A1:E151`：1 行表头、150 条计划。字段如下。

| 列 | 字段 | 类型/格式 | 含义 |
|---|---|---|---|

| B | 频段区间 | 文本，如 `[80,90)` | 频率槽的半开区间 |
| C | 时间区间 | 文本，如 `[35,40)` | 首次使用时间的半开区间 |
| D | 间隔时长 | 非负整数 | 重复使用间空档 |
| E | 使用次数 | 正整数 | 总重复次数 |

已完成的只读质量检查结果：

- 150 个装备编号均唯一且连续：A001–A020、B001–B040、C001–C090；
- 无空字段、无完全重复行；
- 全部频段/时间区间均能解析为 `[整数,整数)`，下界非负且严格小于上界；

这说明附件的主要风险不在缺失或脏数据，而在于**周期展开、区间端点和跨问题约束传递的解释是否统一**。

## 6. 四问的任务拆解与问题间依赖

```text
附件 1 原始计划
      │
      ▼
Q1：周期时频矩形的冲突对检测 ──→ result1.xlsx + 冲突统计
      │
      ▼
Q2：单参数调整/撤销的零冲突重排 ──→ result2.xlsx + 三类保留/调整/撤销统计
      │
      ▼
Q3：在 Q2 无冲突解上增加 C 类计划 ──→ result3.xlsx

Q1 原始冲突 ──→ Q4：允许 C 类调整间隔的重排 ──→ result4.xlsx + 统计
```

### 6.1 Q1：定义正确性优先于算法复杂度

**输入**：150 个原始计划。  
**输出**：所有唯一的冲突装备对及统计。  
**数学对象**：每台装备对应若干个频段相同、时间按固定周期出现的矩形。

本题规模至多展开为 1,300 个单次使用窗。先按频段筛选，再对有频段相交的计划枚举重复使用窗，是可验证的最小充分基线。此时最重要的验证不是运行速度，而是：

1. 半开区间端点相接是否正确判为不冲突；
2. 周期是否使用 $d+g$ 而非误用 $g$；
3. 是否将同一装备对的多次相交去重；
4. 是否按计划对而非单次矩形对填写模板。

### 6.2 Q2：带优先偏好的离散资源重排

**输入**：Q1 冲突关系与全部原始计划。  
**输出**：仅列出需改动或撤销的装备；未列出的装备默认为原样保留。  
**核心难点**：每台装备只能在“保留、仅频移、仅时移、撤销”中选一种状态，且所有保留/调整后状态两两无冲突。

题面偏好可作为一个待确认的词典序候选：

1. 最少撤销；
2. 在此基础上最少调整；
3. 在前两层固定后，最大程度保留高优先级计划；
4. 最后最小化平移总幅度。

这是一种**可解释候选**，并非题面已经指定的唯一优先级。求解前应把最终顺序写入“约束合同”。

### 6.3 Q3：周期二维装填，但先解决容量边界

**输入**：Q2 的完整无冲突排程，而不只是 `result2.xlsx` 中的改动行。  
**输出**：新增 C 类计划的编号、频段区间、首次时间区间。  
**结构解释**：附件中 C 类均为频宽 3、单次时长 2、间隔 8、使用 12 次；而模板只要求填写频段和首次时间。因而“新增计划继承 C 类其余固定参数”是合理推断，仍应在论文中明示为解释。

最关键的未定问题是“**不增加时频资源**”的时间边界。频率边界明确为 100 槽；题面没有给出总体时间窗 $H$。若允许把新增计划无限延后，新增数量没有有限上界。因此，Q3 在进入求解前必须：

- 从官方补充材料确认 $H$；或
- 公开给出可辩护的 $H$ 定义，并将它作为建模假设和敏感性对象。

在 $H$ 已固定后，本质才是：枚举与 Q2 排程兼容的 C 类候选 $(f,s)$，并从中选择数量最大的两两兼容集合。

### 6.4 Q4：Q2 的可行状态扩展，而非 Q2 的简单重复

**输入**：原始计划与 Q1 冲突。  
**输出**：频移、时移、间隔调整或撤销的装备清单和分类统计。  
**新增自由度**：仅 C 类可调整间隔。若采用离散且非负的物理解释，C 类原间隔 8 对应

$$
g'_i\in\{0,1,\ldots,18\},\qquad |g'_i-8|\le10.
$$

调整间隔会改变该计划**所有后续使用窗**的开始时刻；不能只移动第二次使用。与此同时，“一个计划只能调整一个参数”的共同约束仍应适用：选择间隔调整的 C 计划不应再同时频移或时移，除非团队作出不同解释并报告理由。

## 8. 相似问题的解决思路：可迁移之处与不可照搬之处

以下资料用于识别问题结构，**不使用任何 2026 D 题的公开解答或他队结论**。

### 8.1 频率指配问题（FAP）

经典 Frequency Assignment Problem 通常以“通信链路、可选频率域、约束、优化指标”组织实例；[FAP Web 的 CELAR/GRAPH 实例说明](https://fap.zib.de/problems/)展示了这种输入分层。可迁移到本题的是“资源域 + 冲突约束 + 目标”的表达方式；不能照搬的是其静态单频假设，因为本题还具有重复时间窗和连续频段宽度。

### 8.2 无线调度的冲突图与最大权独立集

无线网络调度研究常把干扰关系构造成 conflict graph，并将选择互不冲突任务的目标写成最大权独立集；例如 [Paschalidis 等的无线调度论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC4704814/)采用这一抽象。对本题可迁移的是：

- 节点可表示“计划”或更细的“计划候选调整状态”；
- 边表示两个节点不能同时选择；
- A/B/C 优先级和调整代价可转换为选择状态的比较口径。

但 Q2 不能直接只选原始计划的独立集，因为题目允许平移，状态本身会改变冲突关系；应先定义候选状态再谈冲突图。

### 8.3 约束规划中的可选区间与互斥约束

[OR-Tools 的 CP-SAT 调度文档](https://github.com/google/or-tools/blob/stable/ortools/sat/docs/scheduling.md)说明了区间变量、可选区间和 `NoOverlap` 约束的通用表达。它与本题的关系是：保留/撤销可视作“可选状态”，时间窗是区间，而频率和时间联合互斥可视作二维矩形的非重叠。

不过，本题每个计划有多次周期性出现，且一个平移变量需要同步影响所有出现窗。直接建立二维 `NoOverlap` 模型比预枚举候选状态更紧凑，但验证成本也高。只有当有限状态模型出现实际规模瓶颈时，才值得升级。

### 8.4 本仓库冻结设计先验的可迁移写法

本仓库的历史设计先验不包含本题数值或现成答案，但可借用两种表达模式：

- `CUMCM2025-D037`：将上游输出明确作为下游输入接口。对应本题即 Q1 检测器复验 Q2/Q4，Q2 完整无冲突排程成为 Q3 的输入。
- `CUMCM2024-E010`：候选方案、共同指标和业务决策相邻展示。对应本题即分类保留/调整/撤销表与位移代价、零冲突复验使用同一口径呈现。

这些只迁移论文叙事和验证结构，不迁移历史模型、参数、结果或图形。
