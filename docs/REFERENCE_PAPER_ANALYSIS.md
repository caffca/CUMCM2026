# Reference Paper Analysis

Status: internal reference, not official rule

本文件总结两篇获奖论文对当前仓库的参考价值。它们用于学习“竞赛论文阅读语法”和“有效视觉/证据表达”，不构成官方格式要求。

## Reference A — 2026 高教杯国一等奖论文（矿井多源突水）

### 可借鉴

1. **经典竞赛结构稳定**：摘要 → 问题重述 → 问题分析 → 假设/符号 → 数据预处理 → 分问题建模与求解 → 模型评价与推广 → 参考文献 → 附录。
2. **逐问闭环强**：每一问都能快速找到建模思路、数学模型、求解算法和结果。
3. **模型与题目结构绑定**：图论、事件驱动水流传播、时间依赖最短路等方法直接对应题目物理/网络结构。
4. **结果交付明确**：正文和表格直接回答端点到达、充满时刻、逃生路径等题目要求。
5. **附录代码服务可复现**：核心求解逻辑进入附录。

### 不应机械复制

1. 流程图视觉较传统，可在不改变竞赛语法的前提下做得更轻、更统一。
2. 问题重述和问题分析仍有压缩空间。
3. 部分流程图与正文功能重复，今后需控制页面成本。
4. 图表风格不是获奖的核心门槛，不能把样文视觉偶然性写成 MUST。

### 对仓库的规则影响

- 保留经典竞赛文章骨架。
- 每一问必须形成“建模→求解→结果”的可定位闭环。
- framework diagram 只在真正帮助理解时使用。

## Reference B — 中青杯国一等奖论文（脑电情绪识别）

### 可借鉴

1. **统一的视觉语言**：白底、二维图、热图/条形图/误差图/三线表职责明确。
2. **强 evidence chain**：Spearman + FDR、baseline、LOSO、被试级分析、少样本校准和缺失特征风险均服务于明确问题。
3. **negative / mixed result 如实保留**：耦合多任务没有超过单任务强基线时，正文直接说明“没有稳定提升”；后验校正平均提升很小，也明确收缩结论。
4. **不补造缺失证据**：没有额外缺失采集场景时，只给风险审计框架，不编造实验结果。
5. **跨被试评价口径严格**：标准化、特征筛选、PCA 和参数选择限制在训练被试内部。

### 由于快速成文暴露的可优化项

1. 问题重述与问题分析有较明显重复，可压缩约 25–35%。
2. 若 Table 与 Figure 只是重复同一数值，应根据页面成本删除其一，或明确 exact values vs pattern 的不同职责。
3. 部分 plot 内部 title 与正文 caption 重复，可删除图内 title。
4. 标题不应过度强调一个实际收益有限的复杂机制；标题应反映最强、最稳定的支持结论。
5. 验证链很扎实，但高教杯现场需做 `validation value / page cost` 判断，避免把科研论文全部审计项机械搬入。

### 对仓库的规则影响

- negative / mixed result 不得被 Agent 包装成 success。
- 证据不存在时保持 `not evaluated / insufficient evidence`。
- 图表采用统一 shared style。
- baseline、validation、sensitivity 应与论文 claim 一一对应。

## Combined Production Target

最终目标不是复制任一篇论文，而是：

> **用高教杯国一的竞赛阅读骨架，承载中青杯国一更强的证据链和视觉一致性，同时去掉重复、视觉冗余和科研式过度验证。**

最终论文气质：

> 问题理解深、模型干净、证据充分、结论克制、图表统一、格式严格。
