# 设计与论证模式 — 8篇pilot形成、20篇冻结库保留的暂定经验

与 visual_patterns.md 合计5个模式。单例有原页证据即可调用，不是共识或获奖原因。
来源的奖项身份见INDEX；official_showcase_design不冒充国一。只迁移表达方式，不迁移题设参数。
新增12篇的逐篇可迁移/不可迁移项已进入cards.jsonl；pre-contest freeze不再增加第六种模式。

## P-001 / 上一问输出成为下一问的具名接口

- 触发：多问共享状态、约束或评价量。帮助：读者能追踪依赖，而非只看到算法列表。
- 最小实现：给出“上游输出名/单位 → 下游输入/用途 → 新增条件”；流程节点对应正文任务。沿用已有summary，不新增数据库。
- 来源：CUMCM2025_USER_MINE P10–14、18–20；CUMCM2024-B196 P3–4、8–12、20–22；CUMCM2025-D037 P10–16。3篇/B、D题，暂定跨题支持。
- 边界/反例：种子P5流程图标题属Q1，节点却含Q4内容；B196未完整说明样本量到各σ的转换。有箭头不代表接口真实存在。
- 当前题验证：字段和单位、时间基准、上游不确定性如何传递、代码实际使用了哪些输出；主目标与补充目标须分清。

## P-002 / 结论反查结果与验证对象

- 触发：摘要压缩多问数字，或从模型结果写出“最优/显著/有效”。帮助：保留比较对象与证据强度。
- 最小实现：从现有summary为关键结论指向结果表/图，注明验证的是拟合、搜索、稳健性还是现实效果；负结果与适用范围同处可见。
- 来源：B196 P1对P12/19、P20–23；用户种子P1/8/10–11/22；E010 P8/11/24–27；E061 P14–16（保留局部恶化）；E218 P19/27（局部模拟范围）；E030 P9/14/19–20（观测、估计、预测、干预分层）。6篇/B、D、E题，暂定，不代表普遍共识。
- 边界/反例：B196摘要检测概括与方案表不一致；种子的应检性质不是已完成数值验证；E010前后流量图不单独证明因果；E030把像素换算值称为实际成绩，且一处误差算术不一致。
- 当前题验证：数据版本、指标分母/单位、测试拆分、独立对照和最优性范围。supported_claim成员检查只核对Builder文本，不证明命题。

## P-005 / 候选方法、共同指标、业务决定相邻

- 触发：无现成标签却需要选择可解释的划分/方案。帮助：读者知道为什么最终采用这一方案。
- 最小实现：在同一评价口径下展示真实候选结果与共同指标，再说明如何得到业务切点；缺失候选不伪造补齐。
- 来源：E010 P8–10（候选划分与指标）；B196 P12、19（方案与目标结果邻接）。2篇/B、E题，暂定；“方法选择”与“方案选择”不视为完全等价。
- 边界/反例：E010 P10文字含三个候选，实际该页仅a/b有图、c标题后未见完整第三图；B196均值比较缺少不确定性；E030 P19的模型比较缺独立实测真值，不能只因候选误差更小就外推干预效果。
- 当前题验证：输入窗口一致、指标适用、候选是否完整、误差/区间含义、最终选择是否与指标冲突。不能只凭最高分替代业务约束。
