## 二、问题 1：固定时间资源域的精确上下界

### 2.1 题面明确给出的内容

题面对频率资源给出了明确边界：

- 系统可提供的有限带宽被离散化为 100 个等宽频段；
- 因此使用题面中的无量纲频段编号时，频率资源域可以明确表示为

\[
F=[0,100).
\]

但在时间维度，题面只说明：

- 在“一段时间内”存在大量用频需求；
- 以固定时间长度 `Δt` 作为不可拆分的时间资源基本单位；
- 各计划占用时长必须为 `Δt` 的整数倍。

**题面没有给出总时间长度、总时隙数，也没有给出全局终止时刻 \(T\)。**

因此，严格来说，不能从 PDF 直接得到

\[
T=621,\quad T=643
\]

或任何其他固定时间上界。

### 2.2 原始重复事件的正确递推公式

附件说明用 A001 明确解释了“间隔时长”的含义。

若首次时间区间为

\[
[s,e),
\]

单次持续时间为

\[
d=e-s,
\]

间隔时长为 \(g\)，则下一次占用不是在 \(s+g\) 开始，而是在**上一次占用结束后再间隔 \(g\)** 开始。

因此第 \(k\) 次使用（从 \(k=0\) 开始编号）的时间区间为

\[
T_k=
[s+k(d+g),\ e+k(d+g)),
\qquad k=0,1,\ldots,n-1.
\]

也就是说，相邻两次使用的**起始时刻间距**为

\[
d+g,
\]

而不是 \(g\)。

### 2.3 为什么 `[0,621)` 不成立

若把“间隔时长 8”错误解释为两次使用的起点相隔 8 个时间单位，则会采用

\[
[s+kg,e+kg)
\]

这样的递推方式。这与题面 A001 的例子不一致。

附件1中 C083 的参数为：

- 首次时间区间：`[531,533)`；
- 单次持续时间：\(d=2\)；
- 间隔时长：\(g=8\)；
- 使用次数：\(n=12\)。

按题面给出的递推语义，相邻起点间距为

\[
d+g=2+8=10.
\]

第 12 次占用为

\[
[531+11\times10,\ 533+11\times10)
=[641,643).
\]

对附件1的全部 150 个原始计划按上述规则展开后：

\[
\min t=0,\qquad \max t_{\rm end}=643.
\]

因此，如果为了建模需要用“全部原始重复事件的实际占用范围”构造一个有限时间包络，应使用

\[
\boxed{[0,643)}
\]

而不是 `[0,621)`。

### 2.4 论文中应如何表述

推荐表述：

> 题目明确给出频率资源域由 100 个离散频段构成，因此取频率域为 \([0,100)\)。题面未直接给出全局时间资源终点。为使问题 3 中“不增加时频资源”的约束具有确定的可计算边界，本文依据附件 1 所有原始用频计划，按照题面规定的重复使用规则展开全部占用事件，并以其最小开始时刻与最大结束时刻构造经验时间包络。计算得到原始计划实际占用范围为 \([0,643)\)，故基准模型将其作为固定时间资源域。需要强调的是，\(643\) 为基于附件数据构造的建模边界，并非题面直接给定的时间上限。

### 2.5 一个需要额外注意的问题

如果在 Q2 中允许时间区间向右平移最多 \(5\Delta t\)，而又**不约束调整后计划必须留在 `[0,643)` 内**，理论上 Q2 的最终计划可能延伸到 643 之后。

因此，模型必须二选一并写清楚：

1. **固定资源域方案（更推荐）**：从 Q2 开始就约束所有调整后的计划均位于 `[0,643)` 内，这样 Q3 的“不增加时频资源”具有严格一致性；
2. **Q2 输出包络方案**：先完成 Q2，再以 Q2 最终无冲突计划的实际最大结束时刻定义 Q3 时间域。该方案会使“资源域”依赖 Q2 解，不如第一种解释稳定。

竞赛论文中更建议采用第 1 种，并对时间上界做敏感性分析。

## 三、问题 2：Q3 是否固定 Q2 输出，只新增 C 类计划

### 3.1 结论

\[
\boxed{\text{是，建议固定 Q2 的无冲突计划，只新增 C 类计划。}}
\]

这是目前最符合题面和结果模板的解释。

### 3.2 依据一：“基于问题 2 求解得到的无冲突用频计划”

Q3 的起点明确写为：

> 基于问题 2 求解得到的无冲突用频计划……

这说明 Q2 的结果应被视为 Q3 的已有调度状态。

随后使用“最多**还能安排**多少 C 类用频装备”，语义上更接近：

\[
\text{已有 Q2 调度}+\text{利用剩余资源继续装入新的 C 类计划}.
\]

而不是把 Q2 的所有计划重新打散后进行一次联合重优化。

### 3.3 依据二：result3.xlsx 无法记录对原有计划的再次修改

题目附件说明对 result3.xlsx 的要求是：

> 将新增的 C 类用频装备逐一填写到表格中，其中 A 列填写序号，B 列和 C 列填入相应的频段区间和时间区间。

实际模板列名为：

| A列 | B列 | C列 |
|---|---|---|
| 新增用频装备序号 | 调整后频段区间 | 调整后时间区间 |

模板中：

- 没有“原有设备编号”列；
- 没有用于记录 A/B/C 原有计划再次移动的字段；
- 没有撤销原有计划的字段。

如果 Q3 允许重新优化 Q2 中的原有设备，则官方 result3 模板无法完整表达最终方案，也无法仅凭 result2 + result3 唯一复原新的总体调度。

因此，从结果文件设计反推，最合理的边界是：

\[
\boxed{\text{Q2 最终计划固定，Q3 只求新增 C 类计划。}}
\]

### 3.4 “不限制频段和时间的平移幅度”如何理解

Q2 中明确限制：

\[
|\Delta f|\le 10,\qquad |\Delta t|\le 5.
\]

Q3 则说“不限制频段和时间的平移幅度”。

结合 result3 的结构，建议解释为：

> 在新增 C 类计划的选址过程中，不再受到 Q2 中局部平移幅度的限制，只要新增计划的最终频段和时间区间位于既定时频资源域内，并且与 Q2 已有计划及其他新增计划均不发生冲突即可。

这比解释成“允许重新移动 Q2 的全部计划”更加自洽。

### 3.5 论文中建议明确增加一个假设

推荐写：

> **假设 H3：** 问题 3 以问题 2 得到的无冲突用频计划为固定背景，不再改变问题 2 中各原有设备的最终计划；所谓“不限制频段和时间的平移幅度”，是指新增 C 类计划在既定时频资源域内可自由选择合法的频段位置和首次使用时间位置。

这一假设应明确写出，以消除题面措辞可能产生的歧义。

## 四、问题 3：result3.xlsx 的两个“调整后区间”具体表示什么

### 4.1 结论

\[
\boxed{\text{只表示新增 C 类用频计划最终采用的频段区间和首次使用时间区间。}}
\]

具体填写方式应为：

- **A列“新增用频装备序号”**：新增计划的顺序编号，例如 1、2、3、……；
- **B列“调整后频段区间”**：该新增 C 类计划最终占用的连续频段区间；
- **C列“调整后时间区间”**：该新增 C 类计划第一次使用的最终时间区间。

后续重复使用时刻按照该 C 类计划的间隔和使用次数自动展开，无需在 result3 中逐次列出。

### 4.2 “调整后”三个字不应过度解释

虽然模板表头使用了“调整后频段区间”“调整后时间区间”，但附件说明针对 Q3 使用的是：

> 新增的 C 类用频装备……填入相应的频段区间和时间区间。

因此这里的“调整后”更适合理解为**经过优化安排后的最终区间**，并不意味着每个新增 C 类设备必须存在一个需要与之比较的“原始区间”。

### 4.3 不应写入 result3 的内容

result3 中不应重复写入：

- Q2 中保留不变的 A/B/C 设备；
- Q2 中已经完成频率或时间调整的原有设备；
- Q2 中被撤销的原有设备；
- 对原有计划的再次优化结果。

Q3 的 result3 只承担“新增 C 类计划清单”的功能。

## 五、问题 4：题面是否给出了 C 类定义或统一调度周期

### 5.1 题面层面的结论

\[
\boxed{\text{没有明确给出。}}
\]

题面明确给出的 A/B/C 信息只有优先级：

\[
A>B>C.
\]

即：

- A 类优先级最高；
- B 类其次；
- C 类最低。

题面没有以文字形式规定：

- C 类固定占用几个频段；
- C 类单次使用持续多久；
- C 类间隔时长是多少；
- C 类使用次数是多少；
- C 类是否具有无限周期；
- 整个系统是否具有统一调度周期。

### 5.2 附件1中可以归纳出的“数据事实”

虽然题面没有定义，但对附件1的 150 个计划核验可得到：

| 类别 | 设备数 | 频段宽度 | 单次持续时间 | 间隔时长 | 使用次数 | 相邻起点间距 |
|---|---:|---:|---:|---:|---:|---:|
| A | 20 | 10 | 5 | 60 | 3 | 65 |
| B | 40 | 15 | 3 | 40 | 4 | 43 |
| C | 90 | 3 | 2 | 8 | 12 | 10 |

因此，**在本附件数据中**，90 个 C 类设备确实全部呈现相同的结构参数：

\[
\boxed{w_C=3,\quad d_C=2,\quad g_C=8,\quad n_C=12.}
\]

据此，对 Q3 的“新增 C 类用频装备”，最自然且可复现的建模方式是让每个新增 C 类计划继承这组共同参数。

但论文应写成：

> 根据附件 1 中全部 C 类计划的统计特征，C 类设备在本数据集中均具有频宽 3、单次持续时间 2、间隔时长 8、使用次数 12 的统一结构，因此本文将该共同结构作为问题 3 中新增 C 类设备的计划模板。

不建议写成：

> “题目规定 C 类设备频宽为 3、周期为 8……”

因为题面并没有这样规定。

### 5.3 “间隔时长 8”不等于“调度周期 8”

这是一个容易出错的地方。

对 C 类：

\[
d_C=2,\qquad g_C=8.
\]

按照题面给出的重复规则，相邻两次占用的起始时刻间距是

\[
P_C=d_C+g_C=10.
\]

因此若使用“重复周期”这个词，应该写：

\[
\boxed{P_C=10\Delta t}
\]

而不是 \(8\Delta t\)。

其中：

- \(8\Delta t\) 是两次实际占用之间的空闲间隔；
- \(10\Delta t\) 是相邻两次占用起点之间的时间差。

并且使用次数仅为 12 次，因此这是一个**有限重复计划**，并非无限周期过程。

### 5.4 不存在题面规定的“全系统统一调度周期”

附件数据中：

\[
P_A=5+60=65,\qquad
P_B=3+40=43,\qquad
P_C=2+8=10.
\]

三个类别的重复间距并不相同。

因此题目不存在一个被明确规定的“统一调度周期”。即使数学上可以人为计算这些间距的最小公倍数，也不应把它解释成题目给定的调度周期，因为各计划具有有限使用次数，题面也没有要求周期性循环整个系统。

## 六、建议直接替换到论文中的“1.3 题面对照的边界”

下面这段可直接作为论文或技术 Markdown 中的边界说明。

### 1.3 题面对照的边界

1. **固定时频资源域。** 题面明确将有限带宽离散为 100 个频段，因此频率资源域取为 \([0,100)\)。题面只规定时间离散基本单位为 \(\Delta t\)，未直接给出全局时间资源终点。按照附件说明对所有原始计划的重复事件进行展开，原始事件的最早开始时刻为 0，最晚结束时刻为 643，因此本文在基准模型中采用经验时间包络 \([0,643)\) 作为固定时间资源域。该上界来源于附件数据，而非题面直接规定；后续对其进行边界敏感性检验。

2. **Q3 与 Q2 的衔接。** 问题 3 表述为“基于问题 2 求解得到的无冲突用频计划”继续安排 C 类设备，且 result3 模板只要求填写“新增用频装备序号”及其频段、时间区间。因此本文固定 Q2 的最终无冲突计划，不对原有 A/B/C 计划进行联合重优化，仅在剩余时频资源中安排新增 C 类计划。Q3 中“不限制频段和时间的平移幅度”理解为新增计划在既定资源域内不再受到 Q2 的 \(10\Delta f\)、\(5\Delta t\) 局部平移限制。

3. **result3.xlsx 的输出含义。** result3 仅记录新增 C 类计划。A 列为新增计划序号，B 列为优化后的最终频段区间，C 列为优化后的首次使用时间区间；后续重复占用按 C 类计划的间隔时长和使用次数展开。Q2 中已有设备的最终计划不在 result3 中重复填写。

4. **C 类结构与调度周期。** 题面没有以文字形式定义 C 类统一的频宽、持续时间、间隔时长和使用次数，也没有规定全系统统一调度周期。附件 1 中 90 个 C 类计划均表现为频宽 3、单次持续时间 2、间隔时长 8、使用次数 12，故本文将 \((3,2,8,12)\) 作为新增 C 类计划的数据驱动模板。按照题面“上一次使用结束后再间隔”的定义，相邻两次 C 类占用的起点间距为 \(2+8=10\Delta t\)，故不能把间隔时长 \(8\Delta t\) 直接称为重复周期。

## 七、最终建议

当前四个边界中，最需要立即修正的是原文中的：

> “本文用所有原始重复事件的最晚结束时刻构造临时包络 `[0,621)`。”

应改为：

> **“本文按照题面给出的重复使用规则展开附件 1 中全部原始计划。题面未给出全局时间终点；若采用原始重复事件的实际占用范围构造经验时间包络，则其范围为 `[0,643)`。该边界仅为建模假设，不视为题面直接给定的时间资源上限。”**

其中 `[0,621)` 的结果对应把“间隔时长”错误地当成相邻两次使用的起点间距，与题面 A001 的递推示例不一致。
