# 问题三 C 类装备新增

## 3.1 固定背景与完整模板

问题三固定经用户批准的 `result2.xlsx` 中问题二六撤销方案的 144 个活动计划。工作簿先反向解析并通过 Q2 独立复核，再在剩余 ([0,643)\times[0,100)) 资源中新增 C 类计划，不重新调整或撤销 Q2 计划。

C 类频段宽度为 3，单次时长为 2，间隔为 8，使用 12 次，相邻起点步长为 10。首次起点 ((f_0,t_0)) 对应的完整占用集合为

\[
K(f_0,t_0)=\{(t,f):f\in[f_0,f_0+3),\ t\in[t_0+10k,t_0+10k+2),\ k=0,\ldots,11\}.
\]

因此 (f_0=0,\ldots,97)，(t_0=0,\ldots,531)，共枚举 52,136 个候选，每个模板占用 72 个资源格。

## 3.2 集合装填模型

将固定 Q2 占用集合记为 (O)，先删除 (K_p\cap O\ne\varnothing) 的候选，得到 2,334 个可行候选。令 (y_p\in\{0,1\}) 表示是否新增候选 (p)，模型为

\[
\max\sum_p y_p,\qquad
\sum_{p:c\in K_p}y_p\le1\quad(\forall c).
\]

该约束同时避免新增计划彼此冲突；不能以剩余面积简单除以 72 代替完整重复模板检查。

## 3.3 结果与验证

HiGHS 选中 **141 台**新增 C 类装备并返回 `OPTIMAL`，求解器上界同为 141，`mip_gap=0`。进一步把同一候选集改写为 66,472 条候选两两冲突约束，独立复算仍得到 141；加入 \(\sum_p y_p\ge142\) 后返回不可行。因此，在当前固定背景下，141 的上下界已经闭合。固定 Q2 占用 15,816 个资源格，新增计划占用 10,152 个格，合并后 285 个活动计划共占用 25,968 个不同资源格。

独立验证器重新读取 Q2 动作，展开 Q2 与新增计划的全部重复事件，并检查资源边界、C 类参数、编号、Q2—Q3 冲突、Q3 内部冲突及结果表逐行一致性，全部通过。正式 `result3.xlsx` 按附件模板生成 141 行。

旧 Q2 撤销 19 个时曾得到 203 台；新 Q2 仅撤销 6 个，保留计划更多，剩余容量下降到 141。这两个数对应不同的固定背景，旧 203 已被新结果 supersede。

## 3.4 小结

在当前已冻结六撤销 Q2 方案和基准资源域下，问题三最多新增 141 台 C 类装备。这个最优性是“给定当前 Q2 具体方案”的条件结论，不用于反向选择 Q2。
