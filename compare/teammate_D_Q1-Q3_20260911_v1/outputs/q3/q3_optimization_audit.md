# D 题问题三：求解、优化与最优性审计

状态：`OPTIMUM_PROVED_UNDER_APPROVED_Q2`。

## 1. 结论

在用户批准的 `outputs/q2/result2.xlsx`、固定资源域 `[0,643)×[0,100)` 和完整 C 类模板条件下，最大新增数量已经确定为 **141 台**。

这里的“最大”是有上下界证据的条件最优结论，不是只找到 141 台的可行方案。

## 2. 固定输入与候选完整性

批准的 Q2 工作簿被反向解析为 `q2_input_from_result2.json`，得到 144 个活动计划和 15,816 个已占用资源格。该背景通过连续区间和离散资源格两套冲突检查。

C 类模板参数为：频段宽度 3、单次时长 2、间隔 8、使用 12 次，相邻起点步长 10。完整计划首次起点满足 `f0=0,…,97`、`t0=0,…,531`，因此候选总数为

\[
98\times 532=52,136.
\]

筛除与固定 Q2 背景相交的计划后，剩余 2,334 个合法候选。候选没有抽样，也没有为图形效果增加人工筛选参数。

## 3. 主集合装填模型

对每个合法候选 `p` 定义二元变量 `y_p`，其完整占用集合为 `K_p`：

\[
\max \sum_p y_p,
\qquad
\sum_{p:c\in K_p}y_p\le1\quad(\forall c).
\]

正式模型含 2,334 个二元变量、15,521 条被候选使用的资源格约束和 168,048 个非零系数。HiGHS 返回：

| 项目 | 数值 |
|---|---:|
| 可行解下界 | 141 |
| 求解器上界 | 141 |
| MIP gap | 0 |
| 状态 | `OPTIMAL` |
| 搜索节点数 | 1 |

因此主模型已经闭合到 141。

## 4. 独立重编码与 142 台阈值检验

为避免只依赖一种约束编码，另将 2,334 个候选改写为候选两两冲突图：若两个候选共享任一资源格，则加入

\[
y_p+y_q\le1.
\]

独立模型共产生 66,472 条冲突边约束。其结果仍为：下界 141、上界 141、`mip_gap=0`、状态 `OPTIMAL`。

进一步加入阈值约束

\[
\sum_p y_p\ge142,
\]

求解器返回 `INFEASIBLE`。这给出了“142 台不可行”的直接证据，与 141 台可行见证共同证明最大值为 141。机器可读证据见 `q3_optimality_audit.json`。

## 5. 独立可行性验证

正式方案的 141 个新增计划共占用 10,152 个资源格；与 Q2 合并后共 285 个活动计划、25,968 个不同资源格。独立验证重新检查：

- Q2 与 Q3 的全部重复事件均未越过资源边界；
- Q2—Q3 之间无连续或离散冲突；
- Q3 新增计划之间无连续或离散冲突；
- 连续检查与离散检查完全一致；
- `result3.xlsx` 的 141 行与 `results.json` 逐行一致。

验证结果为 `PASS`。

## 6. 是否存在与 Q2 相同的优化缺口

不存在同类的主目标缺口。

- Q2 的核心字典序前缀已证明，但末级平移量 `S10=775` 仍只是可行上界。
- Q3 题面只要求最大新增数量；该唯一主目标已有 141 台可行下界、141 台求解器上界，以及 142 台不可行证明。因此 Q3 的题面目标已经闭合。
- 141 台可能存在多个等价排布，但“在 141 台最优解中再追求更规则或更集中”属于题面未要求的并列破除目标。当前不人为添加该目标，也不因此改变 `result3.xlsx`。

## 7. 结论适用范围

141 依赖三个固定条件：当前批准的具体 Q2 方案、资源域 `[0,643)×[0,100)`、C 类完整模板参数。若任一条件改变，需要重算；Q3 结论不反向证明其他 Q2 方案更优。
