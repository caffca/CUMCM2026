# Q3 图表审查说明

## 证据

图由 `scripts/plot_q3_additions.py` 读取重算后的 Q3 结果和六撤销 Q2 占用矩阵。左图浅色点为 2,334 个与 Q2 不冲突的完整候选，深色点为 141 个选中计划；右图只做首次时间起点分块计数。

## 含义

图表把“可行候选空间”和“最终装填结果”放在同一入口中，能够直观看到新增计划并非由空闲面积平均分配得到。它不把候选数量、选中数量或时间分布误写成新的优化目标，也不改变 `result3.xlsx` 的计划内容。

## 外观与交付

采用 `VISUAL_STYLE_PROFILE.toml` 的白底、蓝灰主色、绿色结果色和轻网格，画布为 155×92 mm。PDF 和 SVG 为矢量交付，SVG 保留文本元素；PNG 为 400 dpi 预览，另生成灰度 PNG 检查点标、标签和明度层级。

## 审查结论

`KEEP`：标题、坐标轴、图例和直接数值标签均可读；左右图统计口径清楚；彩色与灰度版本均能区分候选和选中结果。图表只支撑“固定当前六撤销 Q2 条件下的候选结构与 141 台结果”。
