# Data Guide

只保留能防止常见错误的约定：

- `data/raw/` 默认只读，不手工覆盖原始附件。
- `data/processed/` 由脚本生成；不要把手工修正当作正式数据处理。
- 关键单位转换、坐标/时间转换和重要清洗操作要能解释。
- 空值、异常值、重复行、编码映射和派生变量按实际问题记录，不机械填表。
- 若涉及预测或统计泛化，明确数据划分、分组、泄漏边界和预处理拟合范围。
- 论文重要结果应能回到处理脚本和清晰的输入/输出路径。
- 只有出现版本混乱、文件损坏、附件身份冲突、严格复现要求或用户明确要求时，
  才额外记录 hash、manifest 或详细版本信息。
