# D 题问题三模型卡

状态：`MILESTONE`（基准场景已完成求解、独立验证和结果表交付）

## 1. 输出

- 输出新增 C 类用频装备数量，单位为“台/个”；
- 输出每台新增装备的新增序号、最终频段区间和首次时间区间，写入 `result3.xlsx`；
- 给出最大性证据：候选数量、求解器状态、上下界/最优间隙和独立事件复算结果。

## 2. 已知量与变量

- 固定输入：Q2 主方案 `outputs/q2/results.json`；资源域 `[0,643)×[0,100)`；
- C 类数据模板：频段宽度 `3`、单次时长 `2`、空闲间隔 `8`、使用 `12` 次；相邻起点步长为 `10`；这些是附件 1 的数据事实，不是题面文字规定；
- 决策变量：对每个整数起点 `(f_0,t_0)` 的完整 C 类候选设 `x_{f_0,t_0}∈{0,1}`；
- 候选范围：`f_0=0,...,97`，`t_0=0,...,531`，每个候选占用 `3×2×12=72` 个离散时频单元。

## 3. 硬约束与目标

1. Q2 最终活动计划固定，不在 Q3 中再次平移、撤销或重优化；
2. 每个新增 C 类候选的 12 个重复事件均位于 `[0,643)×[0,100)`；
3. 新增候选不得与任何 Q2 活动计划冲突；
4. 新增候选之间不得共享时频资源单元；
5. 最大化 `∑ x_{f_0,t_0}`。

等价的资源单元约束为：

\[
\sum_{p:c\in K_p}x_p\le 1-O_c,
\]

其中 `O_c` 是固定 Q2 占用矩阵，`K_p` 是一个完整 C 类有限重复模板。

## 4. 基线与升级

- 基线：扫描全部整数起点，先删除与 Q2 冲突的候选，再做 0-1 集合装填；面积除法只作为松上界，不作为答案；
- 可选升级：若基线无法证明最大性，再使用候选冲突图/最大独立集、分相位分解或更长限时求解，但不得改变 Q2 固定接口；
- 结果进入论文前，必须用独立事件展开程序复核边界、Q2 冲突、新增之间冲突和 C 类参数一致性。

## 5. 主要假设及失败风险

- 将题面“不限制频段和时间的平移幅度”解释为新增计划在固定资源域内自由选择合法起点；若允许扩大时间资源域，答案会改变；
- 将附件中全部 C 类记录的共同结构继承给新增 C 类计划；若题面/官方补充材料另有定义，应替换该模板；
- 时间、频率端点按整数离散单元，区间采用半开语义；端点或连续起点解释变化会改变候选集；
- Q3 不反向参与 Q2 目标选择；否则 `result3.xlsx` 无法单独表达原计划的再次变化，也不再是当前问题的固定接口。

## 6. 成功标准

求解结果能被独立程序从 `result3.xlsx` 重新展开；所有新增事件无边界错误、无 Q2 冲突、无新增间冲突；若求解器给出最优状态，则报告“最多”，否则仅报告“已找到的可行数量”。
