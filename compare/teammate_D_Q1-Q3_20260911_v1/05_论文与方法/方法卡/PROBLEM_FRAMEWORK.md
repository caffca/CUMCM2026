# D题问题架构与协同分析底稿

状态：`DISCUSSION_DRAFT`。本文档区分题面明确要求、当前可复核数据事实和待确认的建模解释，不代表最终模型或论文结论。

## 1. 题面要求（直接来自 D题.pdf）

- 频率资源离散为 100 个连续频段；每个计划占用连续频段，且占用数量保持不变。
- 时间资源以 `Δt` 为基本单位，计划占用时长为整数个 `Δt`。
- 每个计划包含频段区间、首次时间区间、前一次使用结束到下一次开始之间的间隔时长和使用次数。
- 两个计划在时间区间和频段区间都存在交叠时，判定为时频冲突。
- 一个计划只能调整一个参数或撤销；一般不调整使用次数和间隔时长。
- Q2 的频段和时间最大平移幅度分别为 `10Δf` 和 `5Δt`；A、B、C 优先级依次降低。
- Q1–Q4 分别输出到 `result1.xlsx`–`result4.xlsx`，并在论文中给出相应统计结果。
- Q4 允许部分 C 类计划调整间隔时长，且与原间隔时长差异不超过 `10Δt`。

## 2. 当前数据事实

- 附件 1 有 150 条计划：A 类 20 条、B 类 40 条、C 类 90 条。
- 每条计划编号唯一；输入字段没有空值、重复行、公式或隐藏工作表。
- 频段均在 `[0,100)` 内，宽度分别为 3、10、15；时间区间宽度分别为 2、3、5。
- 间隔时长分别为 8、40、60；使用次数分别为 12、4、3；这些参数与类别规模呈稳定对应关系。
- 所有时间和频率端点为整数，适合按离散 `Δt`、`Δf` 资源单元表达。

## 3. 题目逻辑架构

### 3.1 一句话目的

将 150 条“计划级”输入转换为重复使用事件，检测时频冲突，并在不同可调整参数集合下以可解释的优先级规则消解冲突或增加 C 类计划。

### 3.2 讨论版 Mermaid 图

```mermaid
flowchart LR
    A[附件1：150条用频计划] --> B[计划规范化\n解析半开区间与类别]
    B --> C[重复使用事件展开\n[t0+k·(duration+gap), t1+k·(duration+gap))]

    C --> D{频段相交\n且时间相交?}
    D -->|是| E[Q1：冲突图/冲突对\nresult1 + 统计]
    D -->|否| F[无冲突事件对]
    E --> G[冲突集合与资源占用状态]

    G --> H[Q2：有限平移消解\n撤销/调整/优先级/幅度]
    H --> I[无冲突计划集\nresult2 + A/B/C统计]

    I --> J[Q3：固定资源下新增 C 类\n最大化新增数量]
    J --> K[result3 + 最大性验证]

    G --> L[Q4：扩展消解\nC类可调间隔 ≤10Δt]
    L --> M[result4 + A/B/C统计]

    E --> N[Q1独立复算]
    I --> O[Q2约束/目标复核]
    K --> P[Q3可行性/上界复核]
    M --> Q[Q4约束/目标复核]
```

### 3.3 节点与边的含义

| 节点/边 | 含义 |
|---|---|
| 计划规范化 → 事件展开 | 将一行计划转换为按使用次数排列的事件，不改变原始输入 |
| 事件展开 → Q1 判定 | 对任意两计划的任意事件对检查频段、时间两个半开区间是否同时相交 |
| Q1 → Q2 | Q2 处理 Q1 发现的冲突，不能漏掉未直接出现在某一局部示例中的重复事件 |
| Q2 → Q3 | Q3 以 Q2 的无冲突计划集作为已占用资源状态 |
| Q1 → Q4 | Q4 仍以 Q1 检出的冲突为消解对象，只扩展可调参数集合 |
| 各问 → 验证 | 每问都独立检查可行性、口径和结果是否满足该问的硬约束 |

Q2 和 Q4 是从 Q1 分出的两条分析路线，不应在图中画成 Q2 必须先于 Q4 的串行关系；Q3 才真正依赖 Q2 的输出。

## 4. 建议的解题步骤

### Step 0：统一对象和符号

对计划 `i` 定义频段 `[f_i^-, f_i^+)`、首次时间 `[t_i^-, t_i^+)`、单次时长 `l_i=t_i^+-t_i^-`、空闲间隔 `g_i`、次数 `n_i`。PDF 第 2 页 A001 示例确认相邻起点步长为 `l_i+g_i`。第 `k` 次事件为：

```text
频段：[f_i^-, f_i^+)
时间：[t_i^- + k(l_i+g_i), t_i^+ + k(l_i+g_i))，k = 0,...,n_i-1
```

全部运算在离散的 `Δf`、`Δt` 单位中完成，避免浮点边界错误。

### Step 1：Q1 冲突检测

1. 校验输入结构和区间格式。
2. 展开 150 条计划的全部重复使用事件。
3. 对计划对 `(i,j)` 先做频段相交预筛，再检查事件时间相交。
4. 每个计划对只输出一次；重复事件多次相交时另存事件重叠次数作为诊断信息。
5. 生成冲突图、冲突对表、总数、各类别组合统计和计划冲突度。

### Step 2：Q2 有限调整消解

1. 基于 Q1 冲突图生成每个计划的候选动作：频段平移、时间平移、撤销。
2. 频段平移保持宽度不变并留在 `[0,100)`；时间平移不超过 `±5`；频段平移不超过 `±10`。基准方案要求所有重复事件仍位于经验固定时间域 `[0,643)` 内，使 Q2 与 Q3 的资源口径一致。
3. 每份计划至多选择一种动作；次数和间隔保持不变。
4. 对每个候选解重新展开所有事件，检查全局无冲突。
5. 使用明确的字典序目标或等价的分层优化，避免用任意大权重掩盖优先级含义。

### Step 3：Q3 新增 C 类计划

1. 固定 Q2 的无冲突计划集。
2. 从前两问的类别定义和附件记录确认 C 类计划的宽度、时间长度、间隔和次数。
3. 将 Q2 计划展开为二维占用矩阵，以完整 C 类有限重复模板扫描所有可行频率/时间起点。
4. 用资源单元约束建立 0-1 集合装填模型，并同时检查新增计划之间的冲突。
5. 最大化新增数量；用求解器状态、上下界和独立事件复算证明“最多”。详细证据和模型见 `work/intake/DISTRIBUTION_ANALYSIS.md`。

### Step 4：Q4 间隔可调的扩展消解

1. 从 Q1 冲突集合出发，增加 C 类计划的空闲间隔变量 `g'_i`。
2. 要求 `|g'_i-g_i|≤10`；新的相邻起点步长为 `l_i+g'_i`，间隔变化会联动所有后续重复事件。
3. 其余频段/时间调整、撤销、优先级和“一份计划至多调整一个参数”的解释保持一致；基准方案中的全部事件仍位于 `[0,643)` 内。
4. 与 Q2 使用相同的统计口径，重点比较撤销数、调整数、优先级保持情况和调整幅度。

## 5. 验证闭环

| 问题 | 必做验证 | 独立复算/对照 | 失败时的处理 |
|---|---|---|---|
| Q1 | 冲突对唯一、编号来自输入、半开端点正确、所有计划对覆盖 | 区间相交法 vs 离散资源单元占用集合 | 标记实现不一致，不能进入 Q2 |
| Q2 | 所有结果计划无冲突；频移/时移边界满足；每计划至多一个动作；统计加总为 150 | 小规模实例穷举或独立检查器；与不考虑优先级的 baseline 对照 | 回到候选动作或目标层，不只调权重 |
| Q3 | 新增计划自身及与 Q2 计划均无冲突；参数定义一致 | 求解器最优状态 + 资源占用上界/禁忌位置枚举 | 若只有可行解无最优证明，结论写“已找到”而非“最多” |
| Q4 | 新间隔在 ±10 内；全部重复事件重新计算；结果全局无冲突 | 独立按新间隔展开；与 Q2 方案做同口径比较 | 检查间隔联动和“一参数”约束是否被破坏 |

所有正式结果进入论文前，至少做一次与主算法不同实现思路的独立重算；不得从 PNG 或人工填写的表格反推数值。

## 6. 论文写作逻辑

### 6.1 全文主线

```text
问题背景与目标
→ 资源离散化与计划事件化
→ Q1 建立冲突事实
→ Q2 在有限调整下消解

→ Q4 放宽 C 类间隔参数并比较
→ 统一验证、局限与推广
```

### 6.2 建议章节

1. **摘要**：每一问分别写任务、核心模型、关键定量结果和结论；不在结果确定前编写数字。
2. **问题重述**：只保留输入、输出、硬约束和 Q1→Q4 依赖，不照抄整段题面。
3. **问题分析**：说明“计划—事件—冲突图—调整/新增”的对象转换以及 Q2/Q4 并行、Q3 依赖 Q2。
4. **假设与符号**：半开区间、离散单位、类别优先级、动作互斥、时间域和新增 C 类参数必须逐项写明。
5. **数据处理**：给出数据规模、类别分布、事件展开公式、数据质量检查和结果模板接口。
6. **问题一模型与求解**：冲突定义、算法、冲突统计、冲突图/分布图和独立复算。
7. **问题二模型与求解**：候选动作、硬约束、分层目标、求解方法、方案表、A/B/C 统计和可行性验证。
8. **问题三模型与求解**：新增 C 类定义、资源占用、最大化模型、最优性/上界证据和新增方案。
9. **问题四模型与求解**：间隔变量、联动事件、扩展目标、统计结果及与 Q2 的公平比较。
10. **模型评价与推广**：明确数据范围、时间域、新增 C 类假设、参数敏感性和未覆盖场景；不把未验证能力写成优点。
11. **参考文献与附录**：参考算法/领域资料；附录放核心代码或结果生成说明，正式结果文件与论文数字保持一致。

## 7. 已确认边界与剩余选择

1. **统一时间域（已确认）**：Q2–Q4 的基准模型统一采用经验包络 `[0,643)`；所有调整后事件均不得越界。643 来自附件展开，不是题面给定值。边界敏感性取 `H∈{638,643,648}`，并重新执行受影响的 Q2/Q3 流程。
2. **新增 C 类参数（已确认）**：新增对象继承前两问的 C 类定义；附件中的 90 条 C 类计划均为“频段宽度 3、时间长度 2、空闲间隔 8、次数 12”，相邻起点步长为 10。题面没有以文字给出这组统一参数，因此论文应标注为附件数据事实。
3. **Q2/Q4 目标顺序**：建议先最小化撤销，再优先保持 A/B/C，随后最小化调整计划数，最后最小化总调整幅度；需要确认是否采用这个字典序。
4. **Q4 动作互斥**：建议沿用“一个计划只能调整一个参数或撤销”，且调整间隔时重新计算全部重复事件。

统一时间域和新增 C 类参数已经确认。Q1 可以正式运行；Q2/Q4 的目标顺序与动作互斥仍需在对应模型卡中显式确定，确定前不冻结其最终结果。
