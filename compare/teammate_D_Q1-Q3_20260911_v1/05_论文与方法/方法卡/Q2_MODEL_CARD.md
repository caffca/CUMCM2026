# D 题问题二模型卡

状态：`MILESTONE`，主目标最优已证明，后续字典序层为部分证明/当前上界。

## 决策与约束

每个原计划恰选一个 `keep / freq(df) / time(dt) / revoke` 候选。频移 `|df|≤10`，时移 `|dt|≤5`，不能同时调整频率和时间；时长、间隔和使用次数保持不变。候选展开全部重复事件，必须位于 `[0,643)×[0,100)`，每个离散资源格至多由一个活动计划占用。

## 主目标解释

采用精炼方案 B：`R → R_A → R_B → M → M_A → M_B → S_n`，其中 `S_n=Σ(|df|/10+|dt|/5)`。类别优先分别作用于撤销和调整，避免把“高等级保护”和“动作总量”混为同一指标。

## 求解与 gate

CP-SAT 使用 4,582 个候选和 52,939 条资源格团约束。每层保存 incumbent、best bound 和状态；某层未证明时默认立即停止，不固定该层 incumbent 后继续优化后续层。任何更好的独立验证可行解必须立即更新 UB。

当前证据为：`R=6` 的 LB=UB=6；固定 `R=6` 后 `R_A=0` 的 LB=UB=0；独立 CNF/CaDiCaL 阈值证明闭合 `R_B=4`、`M=126`、`M_A=16`、`M_B=34`。正式方案的末级归一化平移量 `S10=775` 仍只作为当前可行上界，不宣称完整字典序全局最优。

## 验证

独立验证器从动作表重建 150 个计划，以连续半开区间和离散资源格两种方法复核全部重复事件。正式方案为 A `4/16/0`、B `2/34/4`、C `12/76/2`（保留/调整/撤销），零冲突、零越界。

## 风险

- 方案 B 是对题面定性优先级的可解释数学化，不是题面给出的数值权重。
- 后续层最优性尚未完全证明；论文必须区分“主目标最优”与“完整字典序最优”。
- Q3 只能消费冻结后的 Q2 方案，不得以新增容量反向选择 Q2。
