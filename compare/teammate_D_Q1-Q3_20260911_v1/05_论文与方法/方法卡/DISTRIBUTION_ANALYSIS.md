## 2. 频段分布证据

- A、B、C 三类计划都覆盖较宽的频率范围，没有按类别划分互不相交的专属频带。
- C 类首次频段起点在 `0–10, 10–20, ..., 90–100` 十个分段中恰好各有 9 条，占本类计划的 10%。这说明 C 类频段位置具有明显的均衡设计特征。
- 展开重复事件后，C 类在十个频率分段中的加权占用量均为 648 个计划单元；A、B 类负载更不均衡。
- 原始计划在全部 100 个频率单元上都出现过占用。按原始时频包络统计，`30–40` 和 `60–70` 的资源单元占用率较高，分别约为 26.91% 和 26.72%；`90–100` 最低，约为 16.24%。

![频段分布](distribution/frequency_distribution.png)

这组证据支持“先按频率起点生成候选，再由完整重复计划的可行性筛选”，不支持简单指定一个固定空闲频段。

## 3. 时间分布证据

- A、B、C 类首次开始时刻中位数分别为 246.5、265.0、264.5，三类都跨越整个主要时间区间。
- C 类首次开始时刻有 84 个不同值，90 条计划没有集中在少数时间点。

## 5. 为什么不能使用“空闲面积除以 72”

一个 C 类计划不是任意 72 个空闲单元，而是以下固定的有限重复模板：

\[
K(f_0,t_0)=\{(f_0+r,\ t_0+10k+s):
r=0,1,2;\ s=0,1;\ k=0,\ldots,11\}.
\]

以临时包络和原始占用作方法演示，可枚举：

- 频率起点 `f_0=0,...,97`；
- 首次时间起点 `t_0=0,...,531`；
- 共 52,136 个完整 C 类候选起点；
- 只有 986 个候选与原始计划完全不冲突，可行率为 1.89%。

![C类候选起点](distribution/raw_c_candidate_feasibility.png)

77.14% 的单元空闲率与 1.89% 的完整模板可行率差异很大，证明空闲资源高度碎片化。面积上界只能作为很松的校验上界，不能作为安排数量或最优性的证据。上述 1.89% 使用的是原始冲突计划，只证明方法必要性，不是 Q3 结果。

## 6. 建议采用的分配方法

### 6.1 第一步：从 Q2 结果建立占用矩阵

将 Q2 中每个保留或调整后的计划展开为重复事件，建立二元矩阵：

\[
O_{t,f}=\begin{cases}
1,&(t,f)\text{ 已被 Q2 计划占用},\\
0,&\text{否则}.
\end{cases}
\]

先独立确认 `O` 没有重复占用，再进入 Q3。

### 6.2 第二步：枚举完整 C 类候选

对资源域内每个整数起点 `(f_0,t_0)` 构造完整模板 `K(f_0,t_0)`。只有满足

\[
\sum_{(t,f)\in K(f_0,t_0)}O_{t,f}=0
\]

的候选才进入优化模型。该步骤相当于用 C 类有限重复模板扫描二维空闲矩阵。

### 6.3 第三步：进行集合装填优化

令 `x_p∈{0,1}` 表示是否选择候选计划 `p`。对每个时频资源单元 `c` 建立约束：

\[
\sum_{p:c\in K_p}x_p\le 1-O_c,
\]

并最大化：

\[
\max\sum_p x_p.
\]

这是一个 0-1 集合装填模型。也可以把候选计划作为节点、候选之间的冲突作为边，转化为最大独立集；资源单元约束通常更紧凑、更容易直接验证。

### 6.4 启发式的角色

频率低负载区、时间低负载区和较优的 `t_0 mod 10` 相位可以用于生成求解器初始解或候选排序，但不能单独承担“最多”的证明。正式结论优先使用整数规划/CP-SAT 的最优状态，并配合独立检查器重新展开全部新增计划。

## 7. Q3 的验证合同

1. **资源边界**：每个新增计划的 12 次事件全部位于固定时频资源域内。
2. **与原计划无冲突**：新增计划与 Q2 输出的所有计划逐事件检查。
3. **新增计划之间无冲突**：不能只检查它们与既有计划的关系。
4. **类别一致**：每个新增计划保持 C 类频段宽度、单次时长、间隔和次数。
5. **结果独立复算**：用与优化模型不同的事件展开程序复核 `result3.xlsx`。
6. **最大性证据**：报告最优状态、上下界及最优间隙；若没有最优证明，只能写“找到的可行新增数量”。
7. **边界敏感性**：对 `H∈{638,643,648}` 分别重新执行受影响的 Q2/Q3 流程，只改变时间终点并保持其他参数和目标顺序一致；报告 Q2 保留/调整/撤销数及 Q3 最大新增数是否变化。不能把数据包络写成题面事实。

## 8. 当前结论

- C 类计划在附件中具有明确、统一的有限重复模板：宽 3、时长 2、空闲间隔 8、相邻起点步长 10、共 12 次。
- 原始计划在频率上广泛覆盖、在时间上分散，二维空闲资源呈碎片化和重复相位结构。
- Q3 已按“Q2 占用矩阵 → 完整 C 类候选扫描 → 0-1 集合装填 → 独立验证”完成基准计算：固定当前六撤销 Q2 主方案时，52,136 个完整候选中 2,334 个可行，最多新增 141 台 C 类装备。
- 上述 141 台由最优状态、相同的 141 上界和独立验证共同支持；它是当前 Q2 方案与 `[0,643)` 基准域下的条件最大值。旧 3,555/203 仅属于已废止的 19 撤销历史背景。
