# 运行与验证说明

## A. 只看结果（推荐比较时使用）

无需安装依赖。直接查看：

- `outputs/q1/summary.md`、`outputs/q1/result1.xlsx`、`outputs/q1/validation.json`
- `outputs/q2/summary.md`、`outputs/q2/result2.xlsx`、`outputs/q2/validation.json`
- `outputs/q3/summary.md`、`outputs/q3/result3.xlsx`、`outputs/q3/validation.json`

验证 JSON 中的 `status` 应为 `PASS`；Q2 最优性证明还要看 `revocation_bound.json`、`proof/` 和 `q2_optimization_audit.md`，Q3 还要看 `q3_optimality_audit.json`。

## B. 安装环境

在本包根目录打开 PowerShell：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-cumcm.txt
```

也可以直接使用已有 Python 3.12 环境。不要把本机 `.venv` 复制给队友。

## C. 重新运行 Q1（轻量）

为避免覆盖正式结果，输出到新目录：

```powershell
py -3.12 -m scripts.solve_q1 `
  --input data/raw/D题/附件/附件1.xlsx `
  --output-dir outputs/_repro_q1
```

将 `outputs/_repro_q1/results.json` 与 `outputs/q1/results.json` 比较。正式 Q1 验证脚本默认读取 `outputs/q1/`，因此不要在未备份时直接运行它覆盖正式验证文件。

## D. 重新运行 Q2（较慢，结果可能是不同的等价可行解）

```powershell
py -3.12 -m scripts.solve_q2_cp_sat `
  --input data/raw/D题/附件/附件1.xlsx `
  --output outputs/_repro_q2/results.json `
  --horizon 643 `
  --scheme wording `
  --mode chain
```

Q2 搜索受时间上限、线程和随机种子影响，重新运行不保证逐行得到同一动作表。论文和比较应以包内已验证的 `outputs/q2/results.json`、`result2.xlsx` 和证明文件为准。

## E. 重新运行 Q3（依赖当前 Q2 结果）

```powershell
py -3.12 -m scripts.solve_q3 `
  --input data/raw/D题/附件/附件1.xlsx `
  --q2-result outputs/q2/results.json `
  --output-dir outputs/_repro_q3 `
  --horizon 643
```

若要验证重新生成的 Q3 JSON，可用：

```powershell
py -3.12 -m scripts.validate_q3 `
  --input data/raw/D题/附件/附件1.xlsx `
  --q2-result outputs/q2/results.json `
  --q3-result outputs/_repro_q3/results.json `
  --output outputs/_repro_q3/validation.json `
  --horizon 643
```

## F. 解释“复现”和“复核”的区别

复核是读取本包中的正式结果，再运行独立验证器确认边界、冲突和模板一致性；复现是重新搜索。Q2 的 CP-SAT 和 SAT 证明属于计算型模型，重新搜索可能找到不同但同目标的方案，不能因为动作表不同就判定模型错误。

## G. 不应运行的目录

不要把 `.git`、`.venv`、`tmp`、缓存或本包以外的旧快照复制进比较包；不要把旧“19/203”结果重新接到当前 Q2→Q3 接口。
