# CUMCM2026 D 题团队论文交接包

本压缩包用于把当前论文、模型结果和证据边界交给队友或新的 Codex 窗口。它不是 Git 仓库完整备份，也不是官方提交包。

## 建议阅读顺序

1. `TEAM_PAPER_HANDOFF_20260912.md`：完整事实台账、模型接口、结果、证据、失败路线和下一步。
2. `WINDOW_PACKET.md`：工作区状态、当前进度、决定记录和显式附件索引。
3. `current_artifacts/main.pdf`：当前 20 页论文 PDF。
4. `paper_source/`：当前论文源稿；修改前先核对主交接台账中的“待同步”项目。
5. `WINDOW_PACKET_attachments/`：Q1—Q4 结果 JSON、验证文件和关键证明。
6. `source_attachments/` 与 `selected_scripts/`：需要重算或核对原始输入时再读取。

## 包含内容

- 当前论文 PDF和当前 Q4 支撑包；
- 当前论文源文件的精简副本，不包含 `paper/rebuild/build/` 的渲染缓存；
- Q1—Q4 的结果、验证、证明摘要和必要证据；
- 题面、附件 1、输出模板和边界对照文件；
- Q1—Q4 的主要求解/核验脚本副本；
- 自动导出的 `WINDOW_PACKET.md`。

## 重要边界

- `paper/tex/` 旧稿没有放入本包，旧稿不作为当前证据。
- `data/raw/` 在原仓库中只读；本包的 `source_attachments/` 只是副本。
- 当前工作副本可能有未提交修改；不要把包内文件的存在误认为已经 commit 或官方冻结。
- Q2 最新结果证据把 `S10=775` 闭合，但论文源稿仍有旧的“可行上界”文字；接手者必须统一摘要、Q2 正文、符号表和附录。
- Q3 的 141 只适用于冻结的具体 Q2 方案；Q4 的 142 调整和 `S10^(4)=943` 只是条件候选，不能写成完整次级最优。

## 复现提示

所有命令和依赖边界见主交接台账第 15 节。建议先在仓库副本或临时输出目录复核，避免直接覆盖正式 `outputs/`。
