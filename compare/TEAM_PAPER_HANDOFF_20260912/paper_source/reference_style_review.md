# 范文排版核验与 TeX 规则修订基线（已审批）

状态：R1--R7 已获用户同意；本文件保留为本轮规范化的规则基线。执行后的 PDF 和 TeX 变更以实际编译与渲染结果为准。

## 1. 先给结论

用户对当前 TeX 的判断是有依据的：当前稿的层级结构已经比较清楚，但“加粗”承担了过多导航任务，模型假设中的每个短标题、摘要中的若干结果锚点、分析中的问题引导句叠加后，视觉黑度高于两篇范文。两篇范文的共同特点不是“所有结果都加粗”，而是：

1. 中文正文基本保持同一种宋体常规字重，英文、数字和公式各自保持稳定的字形系统；
2. 加粗主要用于标题层级、问题引导词和极少数模型/结果短语；
3. 表格和图形承担精确数据，正文只解释比较关系，不用粗体反复强调同一个结论；
4. 页面紧凑来自有效信息、较小的段间距和连续的正文流，而不是通过增大字号、增加空行或把普通句子加粗来“填满”。

因此，建议把当前规则从“重点内容尽量加粗”收紧为“结构加粗、证据少量加粗、普通论述不加粗”。

## 3. 两篇范文共同值得保留的点

### 3.1 摘要不是“加粗结果清单”

两篇范文都把摘要写成连续的普通正文段落。每个问题以一个短的加粗引导语开始，例如“针对问题一”，随后使用常规字重叙述方法、结果和范围。真正加粗的通常是少量方法名或决定性结果，而不是整段句子。关键词行只强调“关键词：”，关键词本身保持常规字重或弱强调。

### 3.2 问题重述和问题分析是连续阅读流

范文 A 的问题重述跨页后接问题分析，范文 B 也没有为了凑一页而把每个小节强行分页。问题分析内部以“问题一：”“问题二：”等加粗短语导航，正文内容不再重复套一层粗体小标题。这个模式与当前希望采用的“问题分析无二级标题”是一致的。

### 3.3 层级标题加粗，正文不跟着变黑

两篇范文都保留顶层标题居中、下层标题左对齐的层级关系，但普通段落保持常规字重。模型假设通常使用编号条目，不把每条假设的名称和整句解释全部加粗。这样既能快速定位层级，又不会让正文失去灰度层次。

### 3.4 表格优先承载精确数字

符号表、结果表和验证表均采用紧凑的横线结构，基本不使用竖线。表前说明“表中字段如何组织”，表后解释实际比较；正文不再用粗体逐项重复表内数字。符号表通常一行一个符号，含义直接、行高紧凑。

### 3.5 图表靠近第一次解释

范文中的图通常紧接在“为什么需要这个图”的正文之后，图注负责识别对象，不在图注中堆叠方法说明。图和表都没有依赖左上角手写“图 1”来编号，编号由排版系统生成或按统一 caption 规则出现。

## 4. 当前 TeX 规则中需要收紧的地方

以下是规则层面的发现，不是对已有科学内容的否定。

| 当前规则/写法 | 产生的视觉问题 | 建议方向 |
|---|---|---|
| `\CUMCMAbstractKey` 对整段数学元组和“最多新增 141 台”使用粗体 | 摘要中结果锚点连续出现，黑度高于范文 B | 每个问题最多保留 1--2 个短结果锚点；数学式只在需要扫描时加粗，其余结果用常规字重和表格承载 |
| 模型假设的每条短标题均 `\textbf{...}` | 连续粗体短语形成“黑色栅栏”，正文解释反而被压低 | 假设改为三条常规编号条目，不加粗整句名称；模型假设与符号说明置于同一个一级标题下 |
| 分析使用摘要引导宏 `\CUMCMAbstractLead` | 字体效果可以复用，但语义上把摘要样式带入正文 | 保留“问题一：”的加粗短引导，另设正文宏；问题分析不设置二级标题，不对后续句子加粗 |
| 所有层级标题统一 `\bfseries` | 标题加粗本身合理，但若再叠加正文粗体，层级差异会变小 | 保留顶层和必要下层标题加粗；取消正文中的装饰性粗体 |
| 正文、公式和图中文字来自多套字体 | 当前 PDF 可见 SimSun/Times、Computer Modern 数学字形，以及图中 Noto Sans SC；科学内容不受影响，但视觉系统略分裂 | 正文中文统一宋体、英文/数字统一 Times New Roman；公式固定一套数学字体；图表统一一套无衬线中文字体，避免同一图混用多种字体 |

## 5. 建议审批的新版排版规则

以下规则拟作为 `paper/rebuild/assets/cumcm-paper-style.tex` 和正文宏的修订依据。

### R1：正文基准字体

- 中文正文：SimSun（宋体），常规字重；
- 英文、数字和拉丁符号：Times New Roman，常规字重；
- 数学公式：固定一个数学字体族，全文不在 Computer Modern、Cambria Math 和其他数学字体之间混用；
- 图表：统一使用一个可覆盖中文字符的无衬线字体，但图表字体不得反过来改变正文的宋体规则。

### R2：加粗的使用边界

只允许以下四类加粗：

1. 顶层标题和确有层级意义的下层标题；
2. 摘要、问题重述、问题分析中每个问题的短引导语；
3. 摘要中每个问题最多 1--2 个短模型/结果锚点；
4. “关键词：”和必要的表头/图表编号标识。

普通解释句、假设说明、模型推导、表后结论和限制条件默认不加粗。不得把一整句、一个整段或连续多个结果值设置为粗体。

### R3：摘要

摘要标题和“摘要”保留加粗；正文采用常规字重。每个问题用一个加粗短引导语开启，后面连续写方法、结果和适用范围。结果优先通过具体数字、公式和表格表达，不使用多个粗体短语制造视觉层次。关键词条目默认常规字重。

### R4：问题重述与问题分析

- “问题背景”“问题提出”保留为问题重述下的二级标题；
- 问题一至问题四用加粗短引导语引出，正文不再套用二级标题；
- 问题分析采用“总述—问题一—问题二—问题三—跨问接口”的连续结构；
- 当前用户明确要求问题分析约占一页，这作为本稿的局部排版目标，不推广为“所有章节必须填满一页”；
- 页面不足时优先删去重复解释，不通过缩小字体、增大字重或增加空行解决。

### R5：模型假设与符号说明

假设使用紧凑的编号列表，仅保留三条会改变冲突判定、候选生成或跨问接口的核心规则，不把假设名称整句加粗。符号表保持“符号—含义”两列，一行一个符号；单位和边界在公式附件或数据预处理正文中说明，不为了填表增加单位列。数据预处理另设一级标题。

### R6：表格和图表

表格继续采用 `booktabs` 三线表，精确数值不在正文中用粗体重复。图表保持独立编号、独立 caption，由 LaTeX 自动生成图号；图内不嵌入“图 n”。图表颜色沿用已确认的 B 方案，但颜色只承担类别语义，不能替代文字、位置或标记。

### R7：段落、空白与分页

保持 2 em 首行缩进、段间距为零、单栏 A4 和约 2.5 cm 页边距。正文页面允许有由公式、表格、图形和章节转换产生的自然空白；符号表为保持表题、表头和表体的阅读完整性，在模型假设结束后作为结构断点分页，其余位置不人为插入空行。

## 6. 通过审批后拟执行的变更顺序

1. 先修订 `assets/cumcm-paper-style.tex` 中的加粗宏和正文宏，保留当前 B 配色；
2. 将摘要中的粗体结果锚点压缩到每问 1--2 个；
3. 将模型假设压缩为三条常规编号条目，并与符号说明合并在同一一级标题下；
4. 保持问题分析无二级标题，只保留加粗问题引导语，并重新编译检查第一页、问题重述、问题分析和模型假设页；
5. 最后复核表格、图注、公式字体和全文黑度，不改变任何数据、模型、统计口径或结论。
