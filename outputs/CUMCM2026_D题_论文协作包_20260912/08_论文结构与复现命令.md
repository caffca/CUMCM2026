# 论文结构建议与复现命令

## 1. 推荐论文结构

### 摘要

摘要至少包含：

- 题目对象：周期性时频计划；
- 核心方法：周期展开、有限状态兼容模型、资源单元团、集合打包；
- Q1 的 297 对；
- Q2 的 `C*=6` 和 `M=120` incumbent（标明证据状态）；
- Q3 的条件最大值 138；
- Q4 的条件性 `C=6,M=115` 结果（若保留）；
- 统一零冲突验证和主要局限。

### 1 问题重述与符号

说明计划参数、周期公式、半开区间、频率域和时间域，以及为什么 `H=643` 是数据推导
的最小覆盖口径。

### 2 数据预处理与冲突检测

给出 1,300 个周期窗、冲突判定式、见证记录、297 对结果和类别组合统计。

### 3 Q2 冲突消解模型

给出状态变量、每计划唯一状态、资源单元团约束、T/P/E 目标协议、求解器状态和零冲突
复验。明确区分严格 `C*=6` 与未闭合 `M=120`。

### 4 Q3 新增容量模型

给出 C 模板、52,136 候选、2,452 兼容候选、最大集合打包、OPTIMAL=138 和独立边模型
复核。强调 Q3 对 Q2 冻结输入的条件性。

### 5 Q4 间隔调整模型

给出 C-only gap 状态、6,103 状态、444,561 条边、当前 `result4.xlsx` 和 `UNKNOWN`
边界。若最终没有闭合首层，必须保留“条件性可行”措辞。

### 6 方案比较、敏感性与局限

对比 T/P/E，不把不同目标协议的方案混成同一最优解；讨论 H=648、Q2 `M≤119`、Q4
`C≤5` 等敏感性和未闭合证明。

### 7 结论

按“严格结论 / 条件结果 / 可行性证据 / 仍需补强”四类总结，不隐藏 UNKNOWN。

## 2. 推荐图表

| 图/表 | 作用 |
|---|---|
| Q1 类别组合柱状图 | 展示 B–C 冲突占比 60.94% |
| Q1 冲突图或二维时频图 | 展示周期矩形和见证 |
| Q2 T/P 目标向量表 | 说明总体数量与优先级保护的代价 |
| Q3 时频占用图 | 展示冻结 Q2 后的新增位置 |
| Q4 动作构成表 | 区分频移、时移、gap、keep、cancel |
| 验证表 | 汇总状态、边界、冲突、上下界和 solver status |

三维 `(time, frequency, usage-index)` 图只能作为局部示意或附录；不能替代二维零冲突
验证，因为使用次数 `k` 是周期索引，不是可独立分配的第三种资源。

## 3. 复现环境

在本压缩包解压后的根目录执行。若系统 Python 不包含依赖，请使用项目配置的 bundled Python runtime。

  --json results/q1/conflicts_reproduced.json \
  --plot-data results/q1/plot_data/q1_conflict_categories_reproduced.json

Excel 和审计文件；`code/` 保留 Q1–Q4 脚本、核心模块和测试。队友可以先读本包的 01–08
文件，再通过相对路径回到原始证据。
