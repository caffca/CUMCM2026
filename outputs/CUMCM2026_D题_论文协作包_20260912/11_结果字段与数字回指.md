## 4. Excel 模板字段语义

| 文件 | 列数 | 数据行语义 | 空值/互斥规则 |
|---|---:|---|---|
| `result1.xlsx` | 3 | 序号、冲突装备 1、冲突设备 2；每个计划对只一行 | 只写冲突计划对，不写重复窗见证 |
| `result2.xlsx` | 4 | 用频装备编号、调整后频段区间、调整后时间区间、是否撤销用频计划 | keep 不写；cancel 只写编号和“是”；调整行只改一个参数 |
| `result3.xlsx` | 3 | 新增用频装备编号、频段区间、时间区间 | 每行一个新增 C 计划；周期参数沿用 C 模板 |
| `result4.xlsx` | 5 | 用频装备编号、调整后频段区间、调整后时间区间、调整后间隔时间、是否撤销用频计划 | keep 不写；cancel 不填区间/间隔；gap 行只改变间隔 |

Excel 是面向题目模板的变更清单，不等于 JSON 中 150 个计划的完整状态表。论文统计应
从 JSON 的完整选择或求解报告读取，不能仅从 Excel 的非空行推断“保留数”。

## 5. 证据状态的最小报告格式

每个优化数字至少同时报告：

1. 固定输入：候选状态定义、`H`、模板参数和目标协议；
2. solver status：`OPTIMAL`、`FEASIBLE` 或 `UNKNOWN`；
3. 对最小化目标给出 incumbent 与 best bound；
4. 独立硬约束复验：冲突数、边界违规数、动作互斥；
5. 若是下游问题，列出上游冻结文件名。

推荐写法示例：

> 在固定 `H=643`、完整周期状态和 T 词典序前缀下，求解器返回 `FEASIBLE` 的
> `M=120`，best bound 为 88，统一检测器复验冲突数为 0。因此 120 被报告为可行
> incumbent，而不宣称为第二层全局最优。

## 6. 改动传播规则

| 改动 | 必须重新运行 |
|---|---|
| `H` 或区间端点语义 | Q1、Q2、Q3、Q4 全部 |
| Q2 冻结排程 | Q3；若 Q4 仍从原始 Q1 求解则不必因 Q2 变化而复制 Q2 行 |
| Q2 目标协议或候选状态 | Q2、Q3；论文方案比较表和图表 |
| Q4 gap 候选或 `|Δg|` 上限 | Q4 全部求解、result4、审计和 Q4 论文段落 |
| 仅更换图表样式 | 不改科学数字，但应重新检查图注和回指 |
