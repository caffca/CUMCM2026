# Q4 结果索引

Q4 从附件 1 的原始 150 个用频计划重新求解，而不是把 Q2 的某一份排程当作
Q4 的约束。与 Q2 相同，采用整数半开资源域
`[0,100) × [0,643)`；仅 C 类计划新增“只改变相邻使用间隔”的合法状态。

## 当前正式产物

| 文件 | 作用 |
|---|---|
| `result4.xlsx` | 当前 T 口径下的可复验条件性 incumbent，按附件 2 的 result4 模板写出 |
| `solver_report.json` | 候选规模、求解层、上下界、选择状态和统一复验结果 |

| `cell_edge_equivalence.json` | 全量状态冲突边与资源单元团的等价性审计 |
| `result4_readback_check.json` | 将 Excel 变更清单与原始计划及 `selected_T.json` 逐行对照 |

## 候选空间

Q4 共生成 6,103 个合法状态，覆盖 150 个计划，每台计划 22–50 个状态。其中
1,521 个为 C 类间隔状态；状态冲突审计边 444,561 条，资源单元团约束 53,679
个。抽取 1,000 条状态边与统一周期检测器复核，结果一致；Q2 的 4,582 个状态
全部包含在 Q4 状态集中，新增部分恰为 C 类 gap 状态。

## 当前解的指标

`result4.xlsx` 来自固定前缀 `C=6, M=115` 后的有界保护层搜索：

| 指标 | 值 |
|---|---:|
| 总撤销 `C` | 6 |
| 总调整 `M` | 115 |
| A 类受扰 / 撤销 | 14 / 1 |
| B 类受扰 / 撤销 | 38 / 5 |
| C 类受扰 / 撤销 | 69 / 0 |
| A/B/C 保持 | 6 / 2 / 21 |
| 频移、时移、间隔移位绝对值和 | 589 / 78 / 61 |
| 整数位移指标 `S_sum`, `S_max` | 806, 10 |
| gap 调整计划数 | 10 |

动作计数为：保留 29、频移 83、时移 22、gap 调整 10、撤销 6。完整 150 行
状态清单保存在 `selected_T.json`；Excel 只列出调整或撤销的 121 行，这是
附件 2 result4 模板的“变更清单”语义。

## 证据边界

- 首层全量 T 搜索（180 s）返回 `C=6` 可行 incumbent，best bound 仅为 1；
- 独立阈值 `C≤5` 搜索（180 s）返回 `UNKNOWN`；
- 固定 `C=6` 的调整层搜索（120/240 s）均找到 `M=115`，best bound 为 81；
- 固定 `C=6,M=115` 的保护层搜索（60/180 s）均找到 `P_A=14`，但下界分别为
  3/4，后续层未闭合。

`cell_edge_equivalence.json` 报告 444,561 条跨计划冲突边全部被资源单元团覆盖，且无额外
冲突对。`result4_readback_check.json` 报告 121/121 行匹配、0 个字段差异。上述重复运行说明当前 incumbent 可复现，但不构成最优性证书。尤其不能把 Q4 的
`C=6` 写成已证明的全局最少撤销数。
- 在固定 `C=6, M=115` 后，`P_A=14` 的层为 `FEASIBLE`，求解器下界为 3；
  后续保护层和位移层尚未闭合。因此当前向量是条件性可行解，不是严格词典序最优。
- 统一验证器展开 1,277 个使用窗，冲突数 0、边界违规 0；这证明排程可行，
  不等于证明目标最优。

建议论文写作使用“在本文固定的 `H=643`、T 目标口径和当前搜索预算下得到的
条件性可行 incumbent”，并同时报告 `UNKNOWN`、下界和 `proven_optimal=false`。
若之后取得 `C≤5` 不可行证书或改进 `M`，应重新生成主文件并更新本索引。
