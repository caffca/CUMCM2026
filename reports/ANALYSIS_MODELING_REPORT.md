## 1. 总体建模框架

```text
题面/附件1(150计划) -> 规范化 canonical_plans.csv -> 统一占用模型 U(i)（时频段×时间窗集合）
  Q1 冲突检测（完全枚举+闭式+位图三实现对账）→ G=(V,E), |E|=297
  Q2 冲突消解（带撤销多选择差分 CSP + 词典序四级 + 阶梯证书）→ result2 + 表1
  Q3 C类最大加装（Q2 无冲突方案上的带冲突装箱/集包装 + 上下界会合）→ result3
  Q4 间隔可扩消解（Q2 模型扩 C 类重定时选项 + 支配界 + 热启动）→ result4 + 表1
  -> 独立 checker 复验（零冲突+合规）-> 数据图表 -> 论文
```

核心数学对象（全问题共用，**占用集合**）：计划 i 的频段 `[f0_i, f1_i)`、首次时间窗 `[t0_i, t1_i)`（时长 d_i=t1−t0）、间隔 g_i、次数 n_i，第 k 次占用窗
`slot_i(k) = [t0_i + k·(g_i+d_i), t0_i + k·(g_i+d_i) + d_i)`，k=0..n_i−1（题面 A001 例证钉死，F-005/ADJ R1）。
计划 i 的**占用单元集** `U(i) = {(f,τ) : f∈[f0,f1), τ∈某 slot 覆盖的整数 Δt 格}`，资源盒 `[0,100)×[0,643)`（ADJ R1/R3）。
**冲突**：`(i,j)∈E ⟺ ∃(f,τ)∈U(i)∩U(j)`（半开区间等价于整数格交，ADJ R7）。

## 假设敏感性预检

### 模糊表述及解释
1. **间隔 g 的语义**（决定一切）：(A) g 为两次占用**之间的空闲**（第k次起点 = t0+k·(g+d)）；(B) g 为**周期**（起点 = t0+k·g）。题面 A001 例证「首次[35,40)、g=60→第二次[100,105)」中 100−35=65=60+5 ⇒ **采 (A)**，(B) 复算冲突对=237 且出现 AA 冲突（与优先级叙述矛盾），排除。
2. **Q3 是否重排 Q2 方案**：(A) Q2 冻结、新增 C 自由落位；(B) 可无限平移 Q2 再插。result3 模板仅 3 列（序号/频段/时间）且无既有计划改动登记位 ⇒ **采 (A)** 为主口径（ADJ R5/D-Q3-001），(B) 作灵敏度。
3. **词典序 vs 加权和**：题面四目标为叙述顺序，无权重数字 ⇒ **采词典序**（撤销≻调整≻优先级≻幅度，ADJ R4），避免任意权重；生产用逐级锁定。
4. **平移是否可越 [0,643)×[0,100)**：(A) 不可越（不增资源）；(B) 可越界延伸。**采 (A)**（ADJ R3）；对 Q4 的 dg>0 使末窗右移（C 放大 11·dg），越界动作直接判无效——R3 截断已实测（99/1530 个 dg 选项被剔除）。
5. **新增 C 装备参数**：沿用附件1 C 模板（宽3/时长2/间隔8/次数12），F-018 由模板列数反推确认（间隔/次数无列）。

### 快速验算与递进性检查
- 口径(A)下三独立实现（区间算术/同余闭式/位图）冲突对**逐字节同 SHA**（1a08941b…，297 对，评审复算 0 差异）⇒ Q1 边集唯一合法。
- 递进性：Q2 若有解把撤销降到 ≤6（当前植入锚），Q3 空闲集随之增大 ⇒ Q3 加装数上界不降（撤销释放资源 ADJ R8）；若 Q2 生产解撤销<6，则 Q3 需在新基座重证（已入 search_limitations）。
- 反例门：若采用「只约束 297 原边」的 Q2 松弛，min Σr=OPTIMAL 0（CH-05/CH-REV 复算证实假象）⇒ 撤销需求由「不新造冲突」逼出，必须用 G* 全势边（防静默失效，写入 §8 校验）。

## 4. 问题一模型（route_id=Q1-R21；辅助 Q1-R52/Q1-R41）

**目标**：输出全部冲突对（result1 每行一对）+ 论文统计。

**求解**：完全枚举 11175 对（精确，复杂度 O(11175·n²) 可忽略）。三实现交叉：(主)逐对区间算术；(闭式)类内同余 `Δ mod P ∈ 残差集 ∧ |Δ|≤(n−1)P+(d−1)`，P=g+d（L2/L7）；(位图)100×643 大整数 AND + 倒排 join。
**校验（Q1-C1）**：三实现对称差=0（硬门）；错误口径(1B)诊断复算=237（仅登记不使用）；植入式随机压力测试作召回诊断（n≈500，±4%量级——论文措辞按评审限定）。

## 5. 问题二模型（route_id=Q2-R51）

**目标**：每计划 a_i∈{恒等}∪{df:1≤|df|≤10}∪{dt:1≤|dt|≤5}∪{撤销}，消解后 `∀(i,j)∈E*: 两终态占用不交`，最小化 (rev, adj, Σw_c·[改或撤], Σ|δ|) 词典序（F-010/F-011/ADJ R4）。
**模型（部分列表着色/多选择差分 CSP）**：域 `A_i` 为全部合法终态（掩码经 R3 边界截断）；对每条 G* 边 (i,j)（i,j 平移后可能共格的对，|E*|=1693）加表格约束 `NOT(mask_i(a)∧mask_j(b)) ∀(a,b) 不可行对`（禁元组 270626）。**关键**：约束必须建在 G*（全势边）而非 E（297），否则「0 撤销」假 OPTIMAL（§3 反例门；文献 L2/L5）。
**求解**：CP-SAT 词典序四级逐级锁定；撤销层加阶梯证书 `Σr≤k` 判 INFEASIBLE（k=0 已证 ⇒ 撤销≥1；生产以小时级预算推界，闭合前论文写区间 [LB,UB]）。侦察 incumbent [6,121,1996,663]（植入锚同值）。
**实现要点**：checker 必须第二独立实现（TF-4）；先判 g'≥1 再算窗（TF-3 evaluator 负例缺陷）；workers=1 复现对照（TF-5）。
**输出**：result2（每改动/撤销计划一行，一行一个调整项）；表1 按类 {保留,调整,撤销}。
**图**：撤销/调整/保留 三类 × A/B/C 分组柱状（表1 图形化）；消解前后冲突数对比 + 词典序四层「目标层级达成」阶梯图（hero 主图候选）。
