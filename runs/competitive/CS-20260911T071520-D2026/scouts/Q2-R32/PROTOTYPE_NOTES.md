# Q2-R32 原型实现说明（异范式：连续重叠体积罚场 → 确定性取整 → 冲突分量局部精确修复）

## 0. 一句话结论
纯连续层**能引导**（取整后残留冲突 297 → 175，减 122 对），但**不能收口**：取整后残留冲突图是
单一巨分量（130/150 顶点），"分量局部修复"退化为全量重解（首个子问题 free=150、
clauses=270626 = 完整 G\* 模型）⇒ 命中 route 预设降级条件
（"修复分量覆盖 >50% 计划 ⇒ 记'引导无增量'降级"）。最终仍得到**可行解**
**(撤销6, 调整123, 优先级损失2205, 幅度762)**（evaluator `feasible=true`，391.07s），
撤销层与精确路线 Q2-R51 打平（6=6），但层2-4 劣于它 ⇒ 异范式可作**上界生成器/热启动源**，
不提供任何证书（lower/upper_bound=null）。

## 1. 口径绑定
同 ADJUDICATION.json：T_MAX=643 资源盒、半开区间、平移越界即动作无效、词典序四级
（撤销·调整·Σw·被改·Σ|δ|，撤销优先级损失 2 倍）、单参数或撤销、数据同 evaluator 列序。
连续层的盒是"题面自带定义域"（F-012 的 10Δf/5Δt）与 R3 的边界交集，**不是人为扩张**：
`δf_i∈[max(-10,-f0_i), min(10,100-f1_i)]`、`δt_i∈[max(-5,-t0_i), min(5,643-末窗结束)]`。

## 2. 模型（阶段 A）
对 G\* 每条边 (i,j)：
- `P^F_ij = max(0, min(f1i+δf_i, f1j+δf_j) - max(f0i+δf_i, f0j+δf_j))`（频段重叠长度）
- `P^T_ij = Σ_{k,l} max(0, min(s_ik+δt_i+d_i, s_jl+δt_j+d_j) - max(s_ik+δt_i, s_jl+δt_j))`
  （F-005 窗端点对 δt 仿射 ⇒ 每项是仿射 max/min ⇒ 凸分段线性）
- `Φ(δ)=Σ_{G*} P^F·P^T + λ Σ_i w_i(|δf_i|+|δt_i|)`，`w={A:1,B:0.1,C:0.01}`，λ=2（跑实验前冻结）
乘积项破坏整体凸性 ⇒ 用**归一化次梯度 + 回溯接受检验**（仅当 Φ_λ 不升才接受，否则步长折半）
⇒ Φ_λ 轨迹按构造单调不升（route 指定的实现正确性哨兵）。子梯度在折点取严格不等式 ⇒ 0。
全确定性：无随机、固定迭代序与破平键（计划编号）。

实测：1409 次迭代（deadline 截断），Φ 2124.0 → **672.18**，amp 36.40；
纯 Φ 上升步 10 次、最大上升 0.0015（λ 交换所致，已如实计数）；盒边界饱和率 0.000。

## 3. 取整与修复（阶段 B/C）
- 取整：按 `|δ-round δ|` 之和降序处理；单参数互斥 ⇒ 只保留 |值| 较大的那一维。
  结果：keep 23 / df 62 / dt 65 ⇒ 残留 G\* 冲突 **175** 对（全恒等为 297）。
- 修复：分量自由集 = 分量顶点 ∪ 一跳 G\* 邻居；子问题=每自由计划选一动作（含撤销）+
  成对不相容子句（自由-自由全量、自由-固定投影成一元禁止），目标用大权重标量化
  `W=(1e15,1e10,1e4,1)` 并**现场断言合法性** `W1>(|F|+1)W2、W2>400(|F|+1)W3、W3>15(|F|+1)W4`。
  子问题恒有"撤销全部自由计划"解 ⇒ 不卡死。1 轮 4 个子问题后残留=0（掩码全量复核=0）。
- 去撤销阶梯（同一局部基座，自由集=被撤销计划 ∪ 一跳邻居，约束"全局撤销数 ≤ k-1"）：
  27→(FEASIBLE,60.4s)→9→(FEASIBLE,60.1s)→5→(UNKNOWN,60.0s) ⇒ 撤销数 28 → 6。
  自由集覆盖 147/150 ⇒ 已接近全量重解，**不构成证书**（bound 仍填 null）。

## 4. 哨兵与门（全部落盘 `sentinel_tests.json`）
1. 解析次梯度 vs 中心差分：最大不一致 **0.0**；
2. `Φ=0 ⇔ 谓词零冲突` 双向用例：全恒等 Φ=2124>0 且冲突 297>0（一致）；全撤销冲突=0（一致）；
3. 半开区间端点相接**负例**：`A001 [80,90)` 平移 δf=-10 ⇒ `[70,80)` 与 `B001 [80,95)`
   重叠长度 = 0（若按闭区间判会假报冲突）；
4. 开发期真实踩到的陷阱（已修并登记 DEV_LOG.md）：G\* 子句集存的是 `(ai,aj)` 元组，
   而状态编码是 `ai*64+aj` 整数 ⇒ 成员测试恒 False，会让 `violated()` 误报 0 冲突、
   修复层空转、直接产出假可行解。**这是本组最危险的一类 bug**（哨兵 2 抓出来的）。

## 5. 结论与对正式建模的建议
- 连续罚场对这种"半开区间 + 周期窗 + 单参数互斥"的离散题**只有启发价值**：
  它把 297 对冲突压到 175，但 Φ=672≫0 且无可行性含义（route 原文："Φ>0 无解可判"）。
- 建议不入选主路线；若保留，定位为**热启动/上界生成器**（把它的动作向量喂给精确路线作 hint）
  与"冲突压力场"可视化素材，正文不得用它宣称任何最优性/可行性证明。
